# Portfolio design rules

These rules apply to this repository. They record the owner's design preferences.

## Motion

- **Keep portfolio headings and artwork static. Reserve motion for brief interaction feedback; add decorative loops or text scrambling only when explicitly requested.**
  Why: keep attention on the content.

## Work listings

- **Work listings use square abstract thumbnails beside the title and category, without UI mockups or text embedded in the artwork.**
  Why: make projects easy to scan while imagery supplies atmosphere.
